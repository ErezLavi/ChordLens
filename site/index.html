MIDI input

Connect a MIDI keyboard and ChordLens auto-connects to the first available device. Or use the computer keyboard mapping.

Chord & scale highlighting

Pick a chord or scale from the menu and the matching keys light up across the keyboard — great for practice.

Chord progressions

Build a progression and play it back with a metronome click, adjustable BPM and optional voice leading.

Ships with a Rhodes SF2, loads your own SoundFont files, and has a mute mode when you only want the analysis.

Installation notes
  • macOS — the DMG is unsigned. On first launch, right-click the app and choose Open, or run xattr -dr com.apple.quarantine /Applications/ChordLens.app.
  • Windows — SmartScreen may warn about an unknown publisher. Choose More info → Run anyway.
  • Android — sideloading the APK requires allowing installs from unknown sources.

Prefer to build it yourself? Clone the repo, run flutter pub get, then flutter run -d macos|windows|android. Requires a Flutter SDK compatible with Dart 3.9.
